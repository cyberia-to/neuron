# Foundations and agent review

The accepted [convergence model](cell-convergence.md) uses one neuron subject
with durable programs. The [complete specification](../specs/README.md) defines
its execution, history, authority and agent composition boundaries.

The [original 2026-09-11 review](../audit/legacy-foundations-agent-review.md)
is preserved as design evidence. Its earlier cell hierarchy is superseded by
the accepted model; its agent capability questions continue in the current
[agent](../specs/agent.md) and [evaluation](../specs/evaluation.md) contracts.
