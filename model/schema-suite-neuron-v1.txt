neuron runtime schema suite revision 1

The UTF-8 bytes of this file participate in schema identities. Incompatible
changes require a new suite and an explicit migration reader. All data uses the
canonical atom/pair/list/uint/ref representation of the retained cell v1 codec.
That original suite remains immutable; its tags and bytes are historical inputs.
NeuronId is the supported native subject identity, not the hash of an activation.

manifest(name) = pair(atom(0x53434831), fields(text(name), ref(blob(this file))))
record(name, fields...) = pair(ref(manifest(name)), fields(fields...))
All records reject extra or missing fields. Maps are sorted unique ref pairs.
Record names below include /1 and fields appear in their declared order.

Lifecycle: installed=0, active=1, paused=2, retiring=3, retired=4.
Invocation status: running=0, waiting=1, joining=2, completed=3, cancelled=4,
  failed=5, conflict=6. Unknown external outcomes are waiting + pending stage 1.
Pending stage: pending=0, attempt-recorded=1, resolved=2, event-wait=3,
  event-resolved=4 (outcome/value present, no external attempt).
Failed is boolean uint 0/1. Other enum values are rejected.

Bounds: max 256 installed progs, 1024 retained invocations, 4096 imports;
  max 256 act tags, 256 children per invocation, 64 parent levels;
  max 1,000,000 steps per invocation, 1000 steps per slice, 8 MiB per artifact.
No secret or host grant is serialized in a checkpoint. The graph owns history.
Held allowances and charged work cannot be recreated by replay or restart.
Program state adoption is conditional on base_revision; stale results conflict.
Children consume parent allowances; terminal parents settle or transfer obligations.
An attempt is durable before dispatch. Unknown outcomes require reconciliation.
